# Face-Based Photo Organizer using FAISS & InsightFace
A fast face-recognition photo organizer that uses InsightFace for face embeddings and FAISS for efficient similarity search. Build the face database once and quickly find photos of one or two people without rescanning the entire folder.

Features:

🔍 Single-person face search
👥 Couple search using one photo
👤👤 Search two people using separate photos
⚡ Fast FAISS vector search
🕶️ Additional sunglasses/goggles-tolerant matching
📁 Automatically copies matching photos to an output folder
💾 Persistent local face database for repeated searches
🖥️ Simple Tkinter GUI
📊 Processing progress and logs


Tech: Python • InsightFace • FAISS • OpenCV • Tkinter • NumPy
